## 📊 6 Business KPIs

| # | KPI | Formula |
|---|---|---|
| 1 | **Implementation Completion Rate** | `AVG(setup_completion_pct)` per client/industry/manager |
| 2 | **Avg Onboarding Time** | `contract_start → go_live` days; SLA-bucketed |
| 3 | **Employee Activation Rate** | `SUM(activated) / SUM(total_employees) × 100` |
| 4 | **Pending Config Issues** | `COUNT` where `status ≠ Resolved`; severity-weighted |
| 5 | **Issue Resolution Time** | `AVG(resolved_date − reported_date)`; `PERCENTILE_CONT` |
| 6 | **Health Score (0–100)** | `(Activation% × 0.40) + (Setup% × 0.35) + 25 − Penalties` |

### Health Score Formula
```
Health Score =
  Activation Rate (%)  × 0.40   [Component A — 40%]
+ Setup Completion (%) × 0.35   [Component B — 35%]
+ 25                             [Base score]
− MIN(open_issues × 2, 25)       [Penalty: open issues]
− MIN(MAX(onboard_days − 25, 0) × 0.5, 15)  [Penalty: time overrun]
− MIN(failed_milestones × 5, 10) [Penalty: failed milestones]
− MIN(critical_open × 3, 15)     [Penalty: critical issues]
```
Clamped to range **[0, 100]**.

## ⚙️ Setup & Run

### Step 1 — Install Python dependencies
```bash
cd 3_python
pip install -r requirements.txt
```

### Step 2 — Configure Database
Edit `3_python/config.py`:
```python
DB_CONFIG = {
    "host":     "localhost",
    "port":     5432,
    "database": "workinsyncd_db",   # ← your DB name
    "user":     "postgres",
    "password": "your_password",    # ← your password
}
```
Or create a `.env` file in `3_python/`:
```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=workinsyncd_db
DB_USER=postgres
DB_PASSWORD=your_password
```

### Step 3 — Create PostgreSQL Database
```sql
-- In pgAdmin or psql:
CREATE DATABASE workinsyncd_db;
```

### Step 4 — Set up DB & Load Data
```bash
python 01_extract_and_load.py --setup
```
This runs `01_schema.sql` → `02_seed_data.sql` → `03_views.sql` in sequence.

### Step 5 — Run KPI Analysis
```bash
python 02_kpi_analysis.py
```

### Step 6 — Generate Excel Report
```bash
python 03_export_excel.py
```
Opens `4_excel_output/WorkInSync_Implementation_Report.xlsx`.

### Step 7 — Build Power BI Dashboard
1. Open Power BI Desktop
2. **Get Data → PostgreSQL Database**
3. Import the 5 views listed in `5_powerbi/powerbi_dax_and_dashboard_guide.md`
4. Set up relationships (star schema)
5. Add all DAX measures from the guide
6. Build 5 report pages as described

## 🔑 SQL Features Used

| Feature | Used In |
|---|---|
| `WITH` (CTEs) | All query files — complex multi-step logic |
| `RANK()` / `DENSE_RANK()` | Completion, activation, health ranking |
| `ROW_NUMBER()` | Milestone ordering, weekly numbering |
| `LAG()` / `LEAD()` | Week-over-week activation delta |
| `PERCENT_RANK()` | Activation percentile, speed percentile |
| `NTILE(4)` | Quartile bucketing of resolution times |
| `PERCENTILE_CONT(0.5/0.9)` | Median and P90 resolution times |
| `FILTER` aggregate | Status-specific counts within GROUP BY |
| `GENERATED ALWAYS AS ... STORED` | Auto-computed `delay_days`, `resolution_days` |
| `CASE WHEN` | Status labels, tier buckets, SLA breach logic |
| `DATE arithmetic` | Duration, delay, overdue calculations |
| `CROSS JOIN` | Portfolio-level benchmarks joined to per-client rows |
| `DISTINCT ON` | Latest snapshot per client |
| Correlated subqueries | Stalling risk dimension in `07_at_risk_alerts.sql` |
| `CONCAT` | Auto-generated insight narratives |
